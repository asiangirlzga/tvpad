# TV Pad

One small Android app for both devices.

- **Phone:** shows the joystick and runs a tiny server.
- **Android / Google TV:** same app auto-detects the TV, finds the phone on the hotspot, and shows the game. No browser.

Use: phone Hotspot on, TV joined to it, open TV Pad on the phone, then on the TV.

Game: `app/src/main/assets/tv.html`. Joystick: `app/src/main/assets/controller.html`. Server: `Relay.java`.
